# tugas-game

Game balap mobil sederhana dibuat dengan HTML, CSS, dan JavaScript.

## Fitur

- Kontrol panah kiri/kanan untuk bergerak
- Start, Pause, dan Reset
- Skor dan High Score dengan penyimpanan localStorage
- Power-up Nitro untuk meningkatkan kecepatan sementara
- Level dan sulit meningkat seiring waktu
- Rintangan yang harus dihindari setiap putaran

## Jalankan

Buka `index.html` di browser, atau gunakan server lokal sederhana:

```bash
python3 -m http.server
```

Lalu buka `http://localhost:8000`.
